# Ata-gith research script library

This repository is organized as a small personal library of molecular-simulation and analysis utilities. The goal is to keep the root directory focused on reusable work and place older or unfinished experiments into archive folders.

## Active / reusable material

The files most likely to be reused as scripts are kept at the top level or in dedicated tool folders:

- `sasa_area.cpp` — analytical solvent-accessible surface area computation
- `Bayesian NN/` — separate project notebook collection; kept as a standalone research project
- `README.md` — repository overview and usage notes

## Archived material

Older, incomplete, exploratory, or one-off files are archived so the root stays clean without losing their history.

- `archive/unfinished/` — draft scripts and incomplete experiments
- `archive/legacy/` — raw outputs, dump-like files, and old experiment artifacts

## Practical usage

Use the root and `scripts/` folder for reusable automation and code. Use archive folders for one-off experiments and historical work.

This repo is intentionally not a production package. It is a research archive with reusable analytical utilities.
